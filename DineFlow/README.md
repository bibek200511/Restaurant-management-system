# DineFlow

A minimalist dark-mode Angular restaurant management app for managing menus, orders, tables, customers, billing, staff, reports, and settings.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Open this project folder in a terminal.
3. Install dependencies: `npm install`
4. Start the development server: `npm start`
5. Open `http://localhost:4200/`.

## Demo logins

- Admin: `admin` / `admin123`
- Manager: `manager` / `manager123`
- Waiter: `waiter` / `waiter123`

## Design updates

- DineFlow branding and minimalist charcoal/emerald dark theme.
- Responsive sidebar with a mobile drawer, accessible menu controls, and larger touch targets.
- Smooth scrolling with reduced-motion support.
- Dark forms, tables, status badges, dialogs, and login screen.

## Recipe photos

Sample recipe photos are stored locally in `images/recipes/` and served by Angular. Food photo artwork is sourced from [TheMealDB](https://www.themealdb.com/); the lime drink photo is from [Unsplash](https://unsplash.com/).


## Visual update
Multi-colour accents (blue, violet, mint, cyan, amber and rose), animated gradient accents, floating orbital glow, entrance transitions and a sign-in button shimmer. Motion respects reduced-motion preferences.
